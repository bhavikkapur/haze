Prototypes

Inside the workshop

Look into the haze workshop with each prototype and concept designed so far.

V0

Haze Core

This model navigates source attribution through low cost sensor networks using reference grade sensor data and regression models to calibrate sensors, along with lab grade source labelled data that serve as ground truth for training ML models to analyse indirect features of particulate matter from the sensors and attribute them to relevant source labels.

Tier 1

Haze Duo

HAZE Duo uses two solar powered cellular nodes installed at opposite boundaries of your site (upwind and downwind). It provides true net dust emissions from your site by continuously calculating the difference between background regional smog coming into the site and the air going out.

Tier 2

Grid Pro

Grid Pro builds on the existing core source-attribution model by adding a distributed network of air-quality monitoring nodes over a designated site, along with added wind direction sensors. The outputs of these nodes, with the measured wind direction and real-time measurements of pollutants using the existing core model, will be used to create a real-time spatiotemporal air pollution map that reflects the pollutant concentrations and distributions across the area in real time. This dynamic representation will allow a more precise identification of likely pollution sources and estimation of their contributions by analyzing spatial concentration gradients, temporal variations and pollutant dispersion patterns.
